# Student Level Pure Python Projects

Simple and clean Python projects for students.  
Har folder mein **sirf ek `main.py`** file hai.

## Projects List

| Folder | Project Name              | What it does                          |
|--------|---------------------------|---------------------------------------|
| 01_todo_list | To-Do List               | Tasks add, view, mark done, delete   |
| 02_password_generator | Password Generator     | Strong password banata hai            |
| 03_quiz_app | Quiz App                  | 5 questions ka quiz + score           |
| 04_expense_tracker | Expense Tracker        | Kharch track karo + total nikaalo     |
| 05_student_marks | Student Marks System     | Marks add, grade, topper              |
| 06_contact_book | Contact Book             | Contacts save, search, delete         |

## How to Run

Kisi bhi folder mein jaake:

```bash
python main.py
```

## GitHub ke liye Tips

- Har project ko alag repo bana sakte ho
- Ya poori folder ko ek repo bana do
